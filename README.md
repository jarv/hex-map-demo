# hex-map-demo

**Live demo: https://jarv.github.io/hex-map-demo/**

A hex map fog-of-war demo built with [Phaser 4](https://phaser.io/). Navigate an escape pod across a procedurally generated hexagonal map where unexplored tiles are hidden by fog of war.

## Features

- Procedurally generated hex map
- Fog-of-war that lifts as you explore
- Smooth movement between hex tiles
- Built with esbuild for fast development and builds

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

Opens a local dev server with live reload.

### Build

```bash
npm run build
```

Output is written to `dist/`.
